# Media

Files the READMEs link to. Keep each under ~10 MB (GIFs: 720 px wide, 10 fps).

| File | Content |
|---|---|
| `mapping_rviz.gif` | RViz while mapping an office floor (cropped, sped up) |
| `amr_driving.gif` | The AMR driving during the same mapping run |
| `amr_base.jpg` | The test AMR with the MID-360 on top |
| `map.png` | Occupancy grid saved by `save_map` (`.pgm` converted to `.png`) |

Raw recordings stay in `raw/`, which git ignores. Upload longer videos to YouTube and link
them from the README instead of committing them.
